────────────────────────────────────────────────────────────────────────────────
Блок 1 — Паѓачко мени на копчето "+ Create" во страничната лента
────────────────────────────────────────────────────────────────────────────────

Копчето "+ Create" се наоѓа во страничната лента. Кога ќе се кликне, се отвора
паѓачко мени со две опции:
  • "Create — Create a recipe manually" → рачно создавање на рецепт
  • "Import — Import a recipe by URL"   → увоз на рецепт преку URL

Пред секој тест корисникот се логира со администраторски credential-и.

────────────────────────────────────────────────────────────────────────────────

TEST 1 — Дали кликањето "Create" ја вчитува формата за рачно создавање рецепт?

  Кликаме на "+ Create" и потоа на "Create a recipe manually".
  Тестираме дали:
    - Насловот "Recipe Creation" е видлив.
    - Полето "Recipe Name" е прикажано.
    - Оранжевото копче горе десно точно покажува "Create Recipe".

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 2 — Дали кликањето "Import" ја вчитува формата за увоз на рецепт?

  Кликаме на "+ Create" и потоа на "Import a recipe by URL".
  Тестираме дали:
    - Насловот "Recipe Creation" е видлив.
    - Секцијата "Scrape Recipe" е прикажана.
    - Полето "Recipe URL" е видливо.
    - [БАГ] Оранжевото копче горе десно го менува натписот за да рефлектира
      увозен контекст ("Import Recipe" или "Scrape Recipe").

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПАЃА.
  ПРИЧИНА: Оранжевото копче сè уште прикажува "Create Recipe" наместо натпис
  поврзан со увоз. Тестот документира UI баг и ќе помине откако ќе се поправи.


────────────────────────────────────────────────────────────────────────────────
Блок 2 — Паѓачко мени на оранжевото копче "Create Recipe" (на страната за
          создавање рецепт, URL: /g/home/r/create/new)
────────────────────────────────────────────────────────────────────────────────

Кога ќе се отвори страната за создавање рецепт, горе десно се наоѓа оранжевото
копче "Create Recipe" со стрелка за паѓачко мени. Тоа мени нуди 6 методи:
  1. Import with URL       — увоз преку URL (Scrape Recipe)
  2. Bulk URL Import       — масовен увоз преку URL
  3. Import from HTML or JSON — увоз од HTML или JSON
  4. Create Recipe         — рачно внесување на рецепт (подразбирано)
  5. Import with .zip      — увоз преку ZIP архива
  6. Debug Scraper         — дебагирање на scraper-от

Пред секој тест: логирање + навигација директно до /g/home/r/create/new.

────────────────────────────────────────────────────────────────────────────────

TEST 3 — Дали кликањето "Create Recipe" го прикажува менито со сите 6 опции?

  Кликаме на оранжевото копче "Create Recipe".
  Тестираме дали сите шест опции стануваат видливи:
  Import with URL, Bulk URL Import, Import from HTML or JSON,
  Create Recipe, Import with .zip, Debug Scraper.

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 4 — Дали опцијата "Import with URL" ја вчитува секцијата Scrape Recipe?

  Кликаме на "Create Recipe" → "Import with URL".
  Тестираме дали:
    - Секцијата "Scrape Recipe" станува видлива.
    - Полето "Recipe URL" е прикажано.

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 5 — Дали опцијата "Bulk URL Import" ја вчитува секцијата за масовен увоз?

  Кликаме на "Create Recipe" → "Bulk URL Import".
  Тестираме дали насловот "Bulk URL Import" станува видлив во содржината
  на страната (по затворањето на менито).

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 6 — Дали "Import from HTML or JSON" ја вчитува соодветната секција?

  Кликаме на "Create Recipe" → "Import from HTML or JSON".
  Тестираме дали насловот "Import from HTML or JSON" станува видлив.

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 7 — Дали опцијата "Create Recipe" враќа на секцијата за рачно создавање?

  Прво навигираме до "Import with URL" за да ја смениме активната секција.
  Потоа кликаме на "Create Recipe" → "Create Recipe" (опцијата во менито).
  Тестираме дали полето "Recipe Name" повторно станува видливо.

  Забелешка: кога е активна секцијата "Scrape Recipe", насловот "Create Recipe"
  во DOM припаѓа само на копчето и на опцијата во менито — тоа го прави
  изборот на точниот елемент посигурен.

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 8 — Дали опцијата "Import with .zip" ја вчитува секцијата за ZIP увоз?

  Кликаме на "Create Recipe" → "Import with .zip".
  Тестираме дали насловот "Import with .zip" станува видлив.

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 9 — Дали опцијата "Debug Scraper" ја вчитува секцијата за дебагирање?

  Кликаме на "Create Recipe" → "Debug Scraper".
  Тестираме дали насловот "Debug Scraper" станува видлив.

  ОЧЕКУВАН РЕЗУЛТАТ: Тестот ПОМИНУВА.


────────────────────────────────────────────────────────────────────────────────
ЗАБЕЛЕШКА ЗА ТЕСТОВИТЕ 5–9
────────────────────────────────────────────────────────────────────────────────

За секциите Bulk URL Import, Import from HTML or JSON, Import with .zip и
Debug Scraper тестираме само дали насловот на секцијата станува видлив.
Подетални assertions (специфични инпут полиња, копчиња) можат да се додадат
откако ќе се погледнат реалните снимки на секоја секција.
