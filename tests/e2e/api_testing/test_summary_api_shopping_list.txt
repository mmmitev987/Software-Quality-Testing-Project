────────────────────────────────────────────────────────────────────────────────
CRUD Синџир — Листи за купување и нивните ставки
────────────────────────────────────────────────────────────────────────────────

TEST 1 — Дали POST /households/shopping/lists создава листа и враќа 201?
  Испраќаме POST со name.
  Тестираме дали одговорот е 201 и листата добива id и userId.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 2 — Дали GET /households/shopping/lists ја содржи нашата листа?
  Испраќаме GET на сите листи.
  Тестираме дали нашата листа е присутна во items масивата.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 3 — Дали GET /households/shopping/lists/{id} ги враќа точните полиња?
  Испраќаме GET на конкретната листа.
  Тестираме дали id, name, userId и listItems масивата се точни.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 4 — Дали PUT /households/shopping/lists/{id} го ажурира иmето?
  Испраќаме PUT со ново name.
  Тестираме дали одговорот е 200 и иmето е сменето.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 5 — Дали POST /households/shopping/items додава ставка во листата?
  Испраќаме POST со shoppingListId, note и checked:false.
  Тестираме дали одговорот е 201 и ставката е во createdItems масивата.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 6 — Дали PUT /households/shopping/items/{id} ја означува ставката checked?
  Испраќаме PUT со checked:true.
  Тестираме дали одговорот е 200 и ставката е во updatedItems со checked:true.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 7 — Дали DELETE /households/shopping/items/{id} ја брише ставката?
  Испраќаме DELETE на ставката.
  Тестираме дали серверот враќа 200.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 8 — Дали DELETE /households/shopping/lists/{id} ја брише листата?
  Испраќаме DELETE на листата.
  Тестираме дали серверот враќа 200.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 9 — Дали GET на избришана листа враќа 404?
  Испраќаме GET на листата избришана во TEST 8.
  Тестираме дали серверот враќа 404 Not Found.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 10 — Дали POST без иmе враќа 201 со name:null?
  Испраќаме POST без поле name.
  Тестираме дали Mealie создава листа со name:null — иmето не е задолжително.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.
