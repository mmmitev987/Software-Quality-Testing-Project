────────────────────────────────────────────────────────────────────────────────
Автентикација — Заштита на ресурси и токен-flow
────────────────────────────────────────────────────────────────────────────────

TEST 1 — Дали GET /users/self без токен враќа 401?
  Испраќаме барање без Authorization header.
  Тестираме дали серверот враќа 401 Unauthorized.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 2 — Дали GET /users/self со лажен токен враќа 401?
  Генерираме 64 случајни знаци и ги праќаме како Bearer токен.
  Тестираме дали серверот ја препознава невалидната JWT потпис и враќа 401.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 3 — Дали логирање со погрешна лозинка враќа 401?
  Испраќаме точна е-пошта (admin) но погрешна лозинка до /auth/token.
  Тестираме дали серверот враќа 401.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 4 — Дали логирање со непостоечки корисник враќа 401?
  Испраќаме е-пошта која никогаш не е регистрирана.
  Тестираме дали одговорот е ист 401 — серверот не открива кои е-пошти постојат.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 5 — Дали успешното логирање враќа 200 и access_token?
  Испраќаме точни admin акредитиви до /auth/token.
  Тестираме дали одговорот е 200 и дали содржи access_token и token_type: bearer.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 6 — Дали валиден токен го дозволува пристапот до /users/self?
  Се логираме, го земаме токенот и го испраќаме до GET /users/self.
  Тестираме дали одговорот е 200, е-поштата е точна и admin:true.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 7 — Дали GET /auth/refresh враќа нов валиден токен?
  Испраќаме Bearer токен до GET /auth/refresh.
  Тестираме дали одговорот е 200, содржи нов access_token и дека тој нов токен
  работи за пристап до /users/self.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 8 — Дали јавниот endpoint /app/about е достапен без токен?
  Испраќаме GET /app/about без Authorization header.
  Тестираме дали одговорот е 200 и содржи поле version.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 9 — Дали обичен корисник на admin endpoint добива 403?
  Создаваме нов корисник (без admin права) и испраќаме GET /admin/about со неговиот токен.
  Тестираме дали серверот враќа 403 Forbidden.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.
