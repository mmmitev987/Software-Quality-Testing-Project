Тестовите се извршуваат строго по ред (test.describe.serial).
Секој тест зависи од резултатот на претходниот.


────────────────────────────────────────────────────────────────────────────────
CRUD Синџир — Регистрација, измена, заштита, бришење
────────────────────────────────────────────────────────────────────────────────

TEST 1 — Дали регистрирањето на нов корисник враќа 201?
  Создаваме нов корисник преку admin API и се логираме.
  Тестираме дали корисникот добива валиден userId и е-пошта.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 2 — Дали GET /users/self го враќа точниот профил?
  Со токенот од TEST 1 испраќаме GET /users/self.
  Тестираме дали е-поштата, id и admin:false се точни.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 3 — Дали PUT /users/{id} ги зачувува новата е-пошта и fullName?
  Испраќаме PUT со нова е-пошта и ново fullName.
  По одговорот со 200, правиме GET /users/self и тестираме дали промените се зачувани.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 4 — Дали PUT на туѓ профил враќа 403?
  Создаваме втор корисник и со неговиот токен се обидуваме да го измениме
  профилот на првиот. Тестираме дали серверот враќа 403 Forbidden.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 5 — Дали обидот за самопроглашување admin враќа 403?
  Испраќаме PUT со admin:true во payload-от на сопствениот профил.
  Тестираме дали серверот го одбива обидот за ескалација со 403.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 6 — Дали DELETE /admin/users/{id} со admin токен враќа 200?
  Со admin токен испраќаме DELETE на тест-корисникот.
  Тестираме дали серверот потврдува бришењето со 200.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 7 — Дали GET на избришан корисник враќа 404?
  Испраќаме GET /admin/users/{id} за корисникот од TEST 6.
  Тестираме дали серверот враќа 404 Not Found.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.
