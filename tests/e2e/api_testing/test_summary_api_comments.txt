Тестовите се извршуваат строго по ред (test.describe.serial).
Два корисници и еден рецепт се создаваат пред сите тестови и се бришат по завршувањето.


────────────────────────────────────────────────────────────────────────────────
CRUD Синџир — Создавање, измена, заштита и бришење на коментари
────────────────────────────────────────────────────────────────────────────────

TEST 1 — Дали POST /comments создава коментар и враќа 201?
  Испраќаме POST со recipeId и text.
  Тестираме дали одговорот е 201 и коментарот добива id.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 2 — Дали GET /comments/{id} го враќа коментарот со user объект?
  Испраќаме GET на коментарот од TEST 1.
  Тестираме дали одговорот е 200 и содржи text, recipeId и user объект.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 3 — Дали GET /recipes/{slug}/comments го содржи нашиот коментар?
  Испраќаме GET на листата на коментари за рецептот.
  Тестираме дали нашиот коментар е присутен во листата.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 4 — Дали PUT /comments/{id} го ажурира текстот?
  Испраќаме PUT со нов text.
  Тестираме дали одговорот е 200 и дали текстот е сменет.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 5 — Дали DELETE на туѓ коментар враќа грешка?
  Со токенот на вториот корисник се обидуваме да го избришеме коментарот на првиот.
  Тестираме дали серверот одбива (403 или 500) и коментарот сè уште постои.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 6 — Дали DELETE со сопствен токен го брише коментарот?
  Со токенот на сопственикот испраќаме DELETE.
  Тестираме дали серверот враќа 200.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 7 — Дали GET по бришење враќа 404?
  Испраќаме GET на избришаниот коментар.
  Тестираме дали серверот враќа 404 Not Found.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 8 — Дали POST /comments без recipeId враќа 422?
  Испраќаме POST само со text, без recipeId.
  Тестираме дали FastAPI враќа 422 Unprocessable Entity.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.

────────────────────────────────────────────────────────────────────────────────

TEST 9 — Дали POST /comments со непостоечки recipeId враќа грешка?
  Испраќаме POST со recipeId кој не постои во базата.
  Тестираме дали серверот враќа 404 или 422.

  ОЧЕКУВАН РЕЗУЛТАТ: ПОМИНУВА.
